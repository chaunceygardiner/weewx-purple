# Translating the demo page

[weewx-purple manual](https://chaunceygardiner.github.io/weewx-purple/) · [weewx-purple on GitHub](https://github.com/chaunceygardiner/weewx-purple) · [Report an issue](https://github.com/chaunceygardiner/weewx-purple/issues)

---

As of 6.0 the demo page is translatable, entirely through WeeWX's own
mechanisms — lang files and `[Texts]`/`$gettext` — the same machinery as
WeeWX's bundled Seasons skin.  There are no invented conventions to learn:
if you have translated a WeeWX skin before, this works the same way.

![The demo page in German](https://raw.githubusercontent.com/chaunceygardiner/weewx-purple/master/PurpleReport-de.png)

## How it works

Every string the page renders is a **gettext-style `[Texts]` key: the
English string is the key**.  A report falls back to English one string at
a time, so a partial translation is fine — a missing key never breaks the
page, it just renders in English.

The words come from three core-standard sources, all merged from
`lang/<lang>.conf` over the skin's own skin.conf:

| What | Where it is translated |
|---|---|
| Page title, heading, "Unavailable", the Day/Week/Month/Year tabs | `[Texts]` |
| Observation labels — the AQI heading and every plot title | `[Labels]` `[[Generic]]` (`pm2_5_aqi`, `pm2_5`) |
| Unit labels — the " AQI" suffix on values, " RGB" | `[Units]` `[[Labels]]` |

The lang files also localize the year plot's date axis
(`[ImageGenerator]` `[[year_images]]` `x_label_format`: day-month instead
of the US month/day), and the plots' day/date footers already follow the
station's OS locale (`%x %X`).  Since the plots are PNG images, a language
change appears as the images regenerate — the day plots on the next report
cycle, the year plot within a day.

## Translating

**German, French, Dutch and Spanish ship with the skin** — `lang/de.conf`,
`fr.conf`, `nl.conf` and `es.conf` are complete translations of the
dictionary, each kept complete by a test, so new strings cannot ship
untranslated.  The plot-period tabs are identical to the translations of
WeeWX's own Seasons skin (a test pins them).  Corrections are welcome —
[file an issue](https://github.com/chaunceygardiner/weewx-purple/issues).
To use one:

```ini
[StdReport]
    [[PurpleReport]]
        lang = de                # or fr, nl, or es
```

For any other language, the skin ships its reference dictionary at
`skins/purple/lang/en.conf` — every string the page renders, and nothing
else (a test keeps it exact in both directions).  To add a language:

1. Copy `en.conf` to `<code>.conf` in the same `lang` directory (e.g.
   `it.conf`) and translate the values — the keys stay English.  Translate
   as much or as little as you like; anything you drop falls back to
   English per string.
2. Point the report at it in `weewx.conf`:

```ini
[StdReport]
    [[PurpleReport]]
        lang = it
```

Further languages are welcome as contributions — a lang file is a
self-contained, no-code contribution.

## One place for the whole station: Defaults

Anything under `[StdReport]` `[[Defaults]]` in `weewx.conf` is merged by
WeeWX into **every** report:

```ini
[StdReport]
    [[Defaults]]
        lang = de                # every skin that ships German goes German
```

`lang = de` selects each skin's own `lang/de.conf` — Seasons, this page and
any other skin that ships German switch together.  A skin with no German
simply stays English: a missing lang file is a logged no-op, never an
error.

`[[Defaults]]` (or the report's own section) is also the durable home for
local overrides: `weectl extension install` overwrites `skins/purple/` —
including its lang files — on every upgrade, while `[[[Texts]]]`/
`[[[Labels]]]` entries in `weewx.conf` survive and are merged over them.

## The dictionary

The reference dictionary as shipped in 6.0 (`skins/purple/lang/en.conf` in
the installed extension is always the authoritative copy for your
version):

```ini
[Labels]

    [[Generic]]
        pm2_5_aqi = Air Quality Index
        pm2_5     = PM2.5

[Units]

    [[Labels]]
        aqi       = " AQI"
        aqi_color = " RGB"

[Texts]

    "weewx-purple demo page" = "weewx-purple demo page"
    "WeeWX-Purple Demo Page" = "WeeWX-Purple Demo Page"
    "Unavailable" = "Unavailable"
    "Day" = "Day"
    "Week" = "Week"
    "Month" = "Month"
    "Year" = "Year"
```
